# 面向上海城市户外运动的健康路线决策 AI Scientist

_徐汇区阶段项目说明与任务状态，更新于 2026-08-22。_

---

## 📋 项目目标

项目面向 XH-202619 赛题，围绕上海城市户外运动场景，组织路线、环境暴露、用户偏好和接驳成本，形成可追踪的路线数据、评价结果与推荐解释。当前阶段聚焦上海市徐汇区。

## 🚀 本地运行

团队成员从 `develop` 获取最新代码：

```powershell
git checkout develop
git pull origin develop
cd .\xuhui_route_builder
```

高德 Key 的申请、自动配置和网站启动命令见 [徐汇路线构建器说明](./xuhui_route_builder/README.md)。真实 Key、`.env` 和 `web/local-amap-config.js` 均保留在成员本机。
