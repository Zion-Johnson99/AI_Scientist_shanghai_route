### 你的需求

用户通过选择题提供：

- 当前位置与搜索范围
- 步行、跑步或骑行
- 运动时间、距离、强度与经验
- 年龄区间及空气、花粉、高温等敏感标签
- 环线、滨水、绿地、安静、厕所、咖啡、补给等偏好

系统结合路线、天气和环境数据，返回一条首选路线，以及“更健康、接驳更近、景观更好”等 2–3 条备选路线，并支持换一批和未来运动计划。

### 评价模型

建议采用“硬约束 → 五维评分 → 可信度修正”：

- 环境健康 35%：PM2.5、花粉、噪声、天气和预警。
- 运动匹配 25%：距离、时长、运动方式、能力、环线或单程。
- 接驳与返程 20%：到起点距离、耗时，以及单程路线终点返程成本。
- 路线质量 10%：验收状态、连续性、绕行、路口和路线形态。
- 兴趣与补给 10%：滨水、公园、咖啡、厕所、便利店等。

同时输出独立的“数据可信度”。缺失和过期数据退出对应指标，并重新分配有效权重；低置信度代理降低结论强度。

### 千问与脚本分工

- 前端选择题直接形成 `UserProfile` JSON。
- 千问检查需求冲突，生成结构化 `UserIntent`。
- Python读取路线目录和环境看板，执行过滤、归一化、评分、排序。
- 先用直线距离筛选候选，再仅对前 5 条调用接驳规划，减少地图 API 消耗。
- 千问读取前三名的分项得分，生成推荐理由、风险提示和替换建议。
- 千问调用失败时，脚本仍能返回稳定排序和模板解释。

百炼支持 OpenAI 兼容接口、JSON Schema 结构化输出和 Function Calling，适合固定输入输出契约。[OpenAI兼容接口](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)、[Function Calling](https://help.aliyun.com/zh/model-studio/qwen-function-calling)

### `evaluation_model_qwen` 构建方式

建议拆成小任务开发：

1. `models.py`、`loaders.py`：定义用户画像、路线特征、评分结果，并通过 `route_id` 合并现有 JSON。
2. `constraints.py`、`scoring.py`、`ranking.py`：完成硬约束、分项评分、可信度和前三名备选。
3. `qwen_client.py`、`service.py`：接入千问结构化输出、超时重试和本地降级。
4. `planner.py`：生成未来计划，并在每次运动前用最新环境数据重新推荐。
