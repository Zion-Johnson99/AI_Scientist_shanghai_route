# Data Semantics

## 三类环境量的语义

| 数据 | 语义 | 空间/时间粒度 | 报告表述 |
| --- | --- | --- | --- |
| PM2.5 | 格网与站点融合估计（和风天气、上海空气质量站点、CHAP 背景） | 54 个约 1 km 网格 | 空间估计，不等同道路旁实时监测仪读数 |
| 花粉 | 日级网格背景，可能含天气条件代理修正 | 约 1 km 网格、按日 | 适合比较日期与区域风险，非瞬时浓度 |
| 噪声 | 0-100 风险代理，来自道路类型、交通邻近、POI、路口、绿地水体等特征 | 约 100 m 路段 | 风险代理，不等同实时分贝 |

## 状态与标记枚举

- `partial`：部分来源或字段缺失。
- `stale`：沿用上一份有效快照。
- `estimated`：模型或代理估计（布尔标记）。
- `ok`：来源齐全且新鲜。
- `error`：来源失败。
- `not_computed` / `not_aggregated`：该量未计算或未汇总（如接驳路径环境）。

## 所有报告必须保留的字段

```text
business_time   # 业务时间（数据描述的时刻/日期）
valid_until     # 有效期（环境块中可用 expires_at 表达）
status          # 状态枚举
spatial_scale   # 空间尺度（如 about_1000m_grid、about_100m_road_segment_proxy）
estimated       # 是否估计（布尔）
confidence      # 置信度（如 low/medium/high）
unit            # 单位（如 µg/m³、0-100 risk index）
```

## 表述边界

- 不把网格 PM2.5 写成道路实测值。
- 不把 0-100 噪声代理写成实时分贝。
- 未来 PM2.5 缺值保留缺值，不从 AQI 反推浓度。
- 接驳路径当前只负责导航，环境暴露尚未汇总；路线库 90 条运动路线已有环境结果。
