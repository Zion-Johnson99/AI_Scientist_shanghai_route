# Hypothesis Rubric

## 评分维度

| 维度 | 分值 | 核心检查 |
| --- | ---: | --- |
| 科学价值 | 0-25 | 是否针对真实知识缺口，而非重复已有结论 |
| 新颖性 | 0-20 | 是否超出 PM2.5 单因素，整合多源暴露、距离约束或个性化 |
| 可证伪性 | 0-20 | 失败条件是否清楚、可由现有数据或实验观察到 |
| 数据可得性 | 0-15 | 当前路线/环境/评价模块与允许来源能否支持 |
| 工程落地 | 0-10 | 结论能否进入路线推荐或网页产品 |
| 表述边界 | 0-10 | 是否避免夸大（候选集约束最优、暴露估计、代理风险） |

总分 100。总分只是选择辅助：Critic 仍必须列出反例和数据风险，不能只凭分数通过。

## 使用规则

1. 每个候选假设逐项打分并给出依据，依据引用 `claim_id` 或模块路径。
2. 可证伪性为 0 的假设直接淘汰，无论总分。
3. `feasibility_score` 与 `scientific_value_score` 写入 `HypothesisCandidate`，供门禁与报告引用。
4. 若多个候选总分接近，优先选择数据可得性与可证伪性更高的假设。
5. 评审记录进入 `HypothesisReview`，包含逐项审查、冲突、缺证据项和最终选择。

## 项目语境中的方向示例

- 多源环境暴露（PM2.5、花粉、噪声、天气）+ 有限附加距离约束 → 个性化效用提升。
- “最优路线”限定为候选集上的约束最优解，不宣称全路网全局最优。
- 环境量均为估计或代理：PM2.5 为格网/站点融合估计，花粉为日级背景或代理风险，噪声为 0-100 风险代理。
