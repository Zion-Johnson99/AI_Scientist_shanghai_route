## 1 11区总方案与数据角色

### 1.1 主链路

路线或用户坐标 → 匹配 `zone_id` → 华风提供天气 → 按分区角色取得空气质量 → 统一字段记录 → 页面展示来源、时间和状态。

11 个分区只决定空气质量的选源方式。温度、湿度、天气现象、风、降水、预报、生活指数和气象预警始终来自华风。`shanghai_station` 与 `district_blend` 只替换空气质量，不替换天气。

空气质量分为三种角色：

| 角色 | 数量 | 空气质量依据 | `is_estimated` |
| --- | ---: | --- | --- |
| `weathercn_direct` | 6 | 华风在代表坐标上返回的真实 LocationKey 和空气质量来源 | 按华风响应口径填写 |
| `district_blend` | 3 | 两个行政区同一时刻的污染物浓度融合，随后按 HJ 633—2026 重算分指数和综合 AQI | `true` |
| `shanghai_station` | 2 | 上海市生态环境局有效站点的小时观测 | 原站点值为 `false` |

CHAP 和 TAP 作为 1 km 日均网格层，承担历史空间细化、跨区域对比和独立验证。它们与当前小时空气质量分开保存，页面标记为“日均网格估计”。

### 1.3 统一记录字段

天气和空气质量按数据族分别生成记录，字段结构保持一致。这样可独立追踪华风天气、华风空气质量、上海站点、跨区融合、CHAP 和 TAP。

| 字段 | 记录要求 |
| --- | --- |
| `provider` | 数据提供方，例如 `weathercn_advanced`、`shanghai_sthj`、`chap`、`tap` 或 `district_blend` |
| `spatial_basis` | `location_key`、`air_quality_source`、`station`、`district_blend` 或 `grid_1km` |
| `spatial_id` | LocationKey、空气质量来源编号、站点编号、融合规则编号或网格编号 |
| `zone_ids` | 使用该记录的一个或多个 11 区标识 |
| `observed_at` | 观测时间、预报有效时间或网格日期，附来源时区 |
| `fetched_at` | 本地取得记录的时间 |
| `values` | 业务值对象，例如综合 AQI、PM2.5 浓度、PM2.5 分指数、温度和湿度 |
| `units` | 与 `values` 同键的单位对象；PM2.5 使用 `µg/m³`，AQI 与分指数使用 `index` |
| `status` | `ok`、`partial`、`stale`、`no_data` 或 `error` |
| `is_estimated` | 站点原值为 `false`；跨区融合和 1 km 网格为 `true` |
| `components` | 融合输入、站点原字段或网格产品信息；直接记录可使用空数组 |
| `source_url` | 官方页面、数据记录或文件来源；认证参数不进入该字段 |

空气质量的 `values` 建议至少保留 `aqi`、`pm2_5_ug_m3` 和 `pm2_5_iaqi`。六项污染物齐全时再生成融合后的综合 AQI；仅有 PM2.5 时只生成 PM2.5 浓度与 PM2.5 分指数，综合 AQI 保持空值。

### 2.2 字段口径修正

- `101.aqi` 是 PM2.5 分指数，建议保存为 `pm2_5_iaqi`。
- `100.aqi` 是综合 AQI，建议保存为 `aqi`。

| --- | ---: | ---: | ---: | --- |

### 2.4 低频研究调用

官方页面暂未提供带版本、配额和服务承诺的公开 API 文档。以下地址来自页面自身异步请求，适合低频研究验证。定时采集前需确认数据方许可，并对字段变化、404、空值和页面改版设置明确错误状态。

```text
POST https://link.sthj.sh.gov.cn/aqi/kqzl/KqzlSitehourlydataController/getSiteHourlyDataBySiteId.do
```

表单参数：

- `lstAqi`：徐汇区页面给出的最新时间。
- `siteId`：`80`、`207` 或 `1`。

PowerShell 单站调用与正确字段解析示例：

```powershell
$pageUrl = 'https://link.sthj.sh.gov.cn/aqi/kqzl/kqzlCountyhourlydataController/subarea/toSubareaDetail.do?groupid=204'
$endpoint = 'https://link.sthj.sh.gov.cn/aqi/kqzl/KqzlSitehourlydataController/getSiteHourlyDataBySiteId.do'

$session = New-Object Microsoft.PowerShell.Commands.WebRequestSession
$page = Invoke-WebRequest -Uri $pageUrl -WebSession $session -TimeoutSec 30
$match = [regex]::Match($page.Content, "var lastLstAqiStr = '([^']+)'")
$latest = $match.Groups[1].Value

$data = Invoke-RestMethod `
  -Uri $endpoint `
  -Method Post `
  -WebSession $session `
  -Headers @{ Referer = $pageUrl; 'X-Requested-With' = 'XMLHttpRequest' } `
  -ContentType 'application/x-www-form-urlencoded; charset=UTF-8' `
  -Body @{ lstAqi = $latest; siteId = '80' } `
  -TimeoutSec 30

$overallAqiByTime = @{}
@($data.'100') | ForEach-Object {
  $overallAqiByTime[[string]$_.lstAqi] = [int]$_.aqi
}

$rows = @($data.'101') | ForEach-Object {
  $observedAt = [string]$_.lstAqi
  [pscustomobject]@{
    observed_at = $observedAt
    station_id = [string]$_.siteId
    station_name = [string]$_.name
    aqi = if ($overallAqiByTime.ContainsKey($observedAt)) {
      $overallAqiByTime[$observedAt]
    } else {
      $null
    }
    pm2_5_ug_m3 = [math]::Round(([double]$_.value * 1000), 1)
    pm2_5_iaqi = [int]$_.aqi
  }
}

$rows | Export-Csv -LiteralPath '.\shanghai_station_pm25.csv' -NoTypeInformation -Encoding utf8
```

采集建议为每站每小时最多一次，同站同小时去重。请求失败或无记录时写入 `partial`、`no_data` 或 `error`，并保留错误上下文；历史值不冒充当前观测。

## 3 跨区融合

### 3.1 三个边界分区

| 分区 | 融合组件 | 空气质量输出 |
| --- | --- | --- |
| 衡复西北 | 徐汇区 + 长宁区 | 同刻污染物浓度融合后重算 |
| 漕河泾西缘 | 徐汇区 + 闵行区 | 同刻污染物浓度融合后重算 |
| 华泾南缘 | 徐汇区 + 闵行区 | 同刻污染物浓度融合后重算 |

三组边界分区的天气继续读取华风。融合记录只覆盖空气质量字段，`provider` 写为 `district_blend`，`spatial_basis` 写为 `district_blend`，`spatial_id` 写入稳定的融合规则编号。

### 3.2 浓度融合与 AQI 重算

两个行政区的空气质量组件均读取华风返回的对应行政区数据。处理顺序为：对齐时间 → 检查单位 → 融合各污染物浓度 → 按 HJ 633—2026 重算各污染物分指数 → 取最大分指数形成综合 AQI → 记录首要污染物和组件。

具体规则：

1. 两个行政区输入使用同一观测时刻或同一有效时段，时间未对齐时状态写为 `partial`。
2. PM2.5、PM10、O3、NO2、SO2、CO 分别在浓度层融合。权重由已确认的边界几何规则提供；权重缺失时停止融合并写入 `no_data`，避免产生未审定数值。
3. 融合后的每项污染物浓度进入 HJ 633—2026 的分段换算表，重新计算对应分指数。
4. 综合 AQI 取全部有效污染物分指数的最大值。禁止直接平均两个行政区的综合 AQI，也禁止把 PM2.5 分指数写成综合 AQI。
5. 任一组件缺少观测时间或六项污染物中的任一项时，`status` 写为 `partial`，保留组件追踪信息，当次不生成融合浓度和 AQI。

`components` 至少记录每个行政区的 `provider`、`spatial_id`、`observed_at`、原始污染物浓度、单位、权重和状态。融合记录的 `is_estimated` 固定为 `true`，便于页面与直接观测区分。

### 3.3 质量门槛

- 两个组件的污染物单位统一后再融合。
- 任一组件过期时，融合结果标记 `partial`。
- 组件观测时间、来源、原始浓度和权重进入统一记录。
- HJ 633—2026 分段边界值由受版本控制的标准表读取，测试覆盖六项污染物的全部边界点和区间插值向上进位规则。
- 页面同时显示“跨区融合”、观测时间和组件来源，避免形成站点实测或 1 km 实测的误解。

### 4.1 数据角色对照

### 4.3 CHAP下载命令

```powershell
$targetDir = 'D:\SJTU\交大\揭榜挂帅\AI_Scientist_develop\weather_api_data\wjx_data\chap'
```

### 4.4 TAP产品事实与人工下载

TAP = Tracking Air Pollution in China。1 km PM2.5 产品融合 10 km TAP PM2.5、1 km MAIAC 卫星气溶胶光学厚度、气象和土地利用信息，通过随机森林生成连续日均网格。

TAP 主页：<http://tapdata.org.cn/>

1 km 下载页：<http://tapdata.org.cn/PM2.5-1km-data-download>

方法论文：<https://doi.org/10.5194/acp-22-13229-2022>

2026-08-24 本机核验快照记录：

- HTTP 主页和 1 km 下载页返回 200。
- 下载页要求登录或注册，提交时使用腾讯验证码。
- 前端提供 CSV 和 NetCDF。
- CSV 支持省域选择或经纬度矩形范围。
- 日均时间范围单次前端校验上限为 366 天。
- HTTPS 在当时的本机环境中证书握手失败。

论文描述近实时模型可更新到前一天，这项描述不代表 2026 年下载服务的现行承诺。取得登录后样本时，将真实可选最后日期写入 `values.dataset_latest_date`。

人工下载步骤：

1. 确认 TAP 官方 HTTPS 登录入口、账号用途、许可、引用和再分发条款。
2. 打开 1 km PM2.5 下载页，选择日均、日期范围和格式。
3. 徐汇试验优先选择 CSV 与矩形范围；完整栅格处理选择 NetCDF。
4. 单次日期范围控制在 366 天内，长时间序列按自然年分批。
5. 完成验证码并提交任务，记录任务时间、真实可选最后日期、文件名、版本和页面提示。
6. 文件保存到 `weather_api_data/wjx_data/tap/`，随后检查大小、时间范围、坐标、单位、缺测值和许可文本。

下载页前端会向登录后的 `/download/data` 提交任务，并携带用户标识和验证码结果。该地址属于内部实现，目前缺少公开 API 文档、稳定字段、配额和服务等级说明。自动化下载需先取得 TAP 团队提供的正式接口或批量数据通道。

### 4.5 1km数据验证

取得 CHAP 或 TAP 文件后执行同一组验证：

1. 校验文件名、大小、哈希、产品版本、许可和来源记录。
2. 读取变量名、坐标名、坐标参考系、空间范围、单位、缺测值和日期时区。
3. 裁剪徐汇区后统计网格数量、空值比例和边界格数量。
4. 将徐家汇站和冠生园路458号站映射到对应网格，比较同日网格值与站点日均值。
5. 给漕河泾和西岸选择固定代表坐标，比较同日网格值、网格编号和产品版本。
6. 沿路线每 100 至 250 m 取样，映射到网格后按经过长度聚合，并对重复网格去重。
7. 输出 `provider`、`spatial_basis=grid_1km`、`spatial_id`、`zone_ids`、`observed_at`、`fetched_at`、`values`、`units`、`status`、`is_estimated=true`、`components` 和 `source_url`。
