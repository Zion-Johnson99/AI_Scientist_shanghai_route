# 徐汇区噪声观测数据

数据来源为上海市公共数据开放平台“数据上链_噪声环境监测数据”，数据集编号 `O5485687412025006`，来源部门为上海市生态环境局。

- 数据页面：<https://data.sh.gov.cn/view/detail/index.html?id=O5485687412025006>
- 下载日期：2026-08-27
- 原始 CSV：`xuhui_noise_monitoring/origin_data/shanghai_noise_monitoring.csv`
- 原始文件大小：42,134,999 字节
- SHA-256：`1B507DC78673C51D10CF40040F5D0D7AF06B3BB0DF18E363D71C617ADF5396E3`

`xuhui_data/xuhui_noise_observations.csv` 保存徐汇四个站点清洗后的观测。清洗包含行政区点位筛选、删除标记过滤、LAeq 与分位指标物理范围检查、时间解析，以及按站点和监测时间保留最新记录。

`xuhui_data/xuhui_noise_baseline.json` 保存站点与徐汇区 LAeq 中位数基线、样本量、时间范围、丢弃原因和来源哈希。当前有效观测 2,525 条，覆盖 2021-01-01 至 2025-07-13。

四个点位编号为 `310104320001`、`310104330002`、`310104340004`、`310104340006`。公开文件缺少站点经纬度，当前基线用于校准全区 0–100 噪声风险分的整体尺度；路线局部差异继续由道路、POI、路口、声功能区和绿地水体特征提供。

原始 CSV 体积较大且已由 `.gitignore` 排除。API token 仅放在本地 `.env`，不会进入数据文件、日志或 Git。
