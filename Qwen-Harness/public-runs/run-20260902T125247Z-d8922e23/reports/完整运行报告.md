## 4. 一次集中修正内容

本轮只执行了一个 `correction_batch`（`iterations/correction_batch.json`，`batch_id = correction_batch_1`，`is_single_batch = true`），未重新生成整个工程，未再次读取成品页面。

修正目标取自盲测差距清单中标记为「计划在集中修正中处理」的条目 `[1, 2, 4, 5, 6, 8, 11]`。

### 4.1 根因

`route_spatial_quality` 失败与三个工程质量门禁失败（`pytest:weather_api_data`、`Node 契约测试`、`评价 API 健康检查`）同源：路线组合只有 87 条，`bike` 第 2 距离带缺 3 条。徐汇区外包矩形约 $8.1\ \text{km} \times 13.2\ \text{km}$，一条 25 km 单程路线必须在区内反复折返才能凑足里程，可行解本就稀少——`commands/probe_bike_band2.json` 测得 16 个 bike 锚点中只有 3 个存在可行的 25 km 端点对（候选对数分别为 66、285、333）。默认生成顺序先填 band 0 与 band 1，长距离南北走廊被短路占用后，band 2 的候选被几何重叠筛查逐条淘汰。

### 4.2 已测量的杠杆

| 编号 | 杠杆 | 结果 |
| --- | --- | --- |
| L0 | 扩大 bike 图（放宽 `MODE_ALLOWED`） | 阅读代码后否决，未实施 |
