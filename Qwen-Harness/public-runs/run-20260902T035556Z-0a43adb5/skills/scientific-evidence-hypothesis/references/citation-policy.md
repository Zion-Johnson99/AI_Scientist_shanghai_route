# Citation Policy

## 核心原则

1. 先注册来源，后生成 Claim；Claim 只引用已注册来源的 `source_id`。
2. 模型不得创建新的作者、DOI、PMID、年份或数值。
3. 证据不足时返回缺口，不补写。
4. 引用只来自来源注册表；不存在于注册表的 `source_id` 一律被引用门禁拒绝。

## 允许的权威来源

- 用户提供文件（`local_file`）。
- PubMed 元数据与摘要（`pubmed`）。
- Crossref DOI 元数据（`crossref`）。
- 官方政府或数据平台页面（`https_url`，仅 HTTPS、允许域名）。
- 仓库内可追溯的代码、配置和数据产物（`repository_file`，附文件路径与 SHA256）。

## CitationGate 检查项

- `source_id` 存在于来源注册表。
- 证据位置（页码、章节、摘要字段或模块路径）存在。
- `verification_status` 达到要求（核心结论要求 `verified`）。
- 结论中的数值能追溯到 Claim 或模块结果。
- 参考文献去重。
- 标题、DOI、PMID 的组合一致。

## 核验率门禁

EvidenceGate 要求参考文献核验率达到 100%。任何无法核验的核心引用触发停止条件，必须从结论中移除或降级为非核心背景。

## 表述边界

- 区分观测事实、模型估计、代理变量和推断。
- 产品结论使用“当前候选集中的约束最优路线”。
- 不把网格 PM2.5 写成道路实测值；不把 0-100 噪声代理写成实时分贝。
