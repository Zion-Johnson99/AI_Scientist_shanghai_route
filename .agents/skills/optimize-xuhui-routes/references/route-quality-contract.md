# 徐汇运动路线质量契约

## 1. 90 条组合结构

路线总数固定为 90 条，步行、跑步、骑行各 30 条。每种运动按以下三个里程档各安排 10 条：

| 运动 | 短距离 | 中距离 | 长距离 |
| --- | --- | --- | --- |
| 步行 | 0.5–2 km | 2–3.5 km | 3.5–5 km |
| 跑步 | 1–5 km | 5–10 km | 10–15 km |
| 骑行 | 5–10 km | 10–20 km | 20–30 km |

区间边界归入从该边界起始的下一档，最后一档包含上界。例如 2 km 步行归入 2–3.5 km，5 km 步行归入 3.5–5 km。

每种运动以 15 条 `strict_loop`、15 条 `one_way` 为设计目标。正式验收允许每种运动 14–16 条 `strict_loop`，其余为 `one_way`。配额调整服从真实路网和拓扑门禁，失败环线更换骨架或转移环线名额。

## 2. 路线形态

| 形态 | 几何要求 | 地图语义 |
| --- | --- | --- |
| `one_way` | 起终点不同，沿单一方向连续推进，无局部往返 | 独立起点、终点和全程方向箭头 |
| `strict_loop` | 首尾闭合并形成单一简单环，无共线入口段、支叉、8 字交叉、双环或重复走廊 | 单一“起终点”标记和全程方向箭头 |

单程路线的起终点直线距离高于 200 米。严格闭环首尾距离不高于 30 米。缺少独立返回廊道时，优先采用单程设计。

### 有效闭环

首尾距离只描述坐标闭合。严格闭环还需同时满足：

1. 轨迹吸附后形成一个连通分量。
2. 图的环秩为 1，每个节点度数为 2。
3. 全图只有一个清晰主环，覆盖一个连贯空间区域。
4. 无哑铃形、葫芦形、双叶形、长柄环或两个环共用连接段。

出现多个环、异常度数节点或重复连接段时标记 `false_loop_topology`。里程不足时缩短目标距离或改为单程。

## 3. 硬性几何门槛

| 检查项 | 门槛 |
| --- | ---: |
| 连续性 | 单一连续 `LineString`，至少两个有效坐标 |
| 严格闭环拓扑 | 单一连通分量、环秩为 1、节点度数均为 2 |
| 重复无向边 | 累计比例不高于 2% |
| 单条重复边 | 低于 30 米 |
| 局部折返 | 地图上无可感知折返；短刺探测为失败信号 |
| 分叉或自交 | 清零；路线图节点度数高于 2 时进入人工复核 |
| 步行、跑步途经点偏移 | 不高于 50 米 |
| 骑行途经点偏移 | 不高于 100 米 |
| 高德距离与几何长度误差 | 不高于 3% |
| 实际距离与目标里程误差 | 不高于 15% |
| 徐汇区内轨迹比例 | 达到 90%，已批准跨区连接场景除外 |
| OSM 可通行路网贴合率 | 达到 98% |
| 同类型双向轨迹重合率 | 低于 90% |

自动门槛用于筛除明显问题。最终还需浏览器地图验收。

## 4. 常见失败形态

| 地图表现 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 地铁站附近出现矩形回环 | 节点落在道路另一侧或分段路由各自选择入口 | 删除该导航节点，改用主路交叉口 |
| 进入景点后原路退出 | 景点位于尽端、院内或单一入口 | 转为沿线 POI，主线留在公共道路 |
| 一条线出现视觉分叉 | 共用路段重复经过或节点顺序跨越 | 重画主骨架，减少节点，重新排序 |
| 闭环带长入口柄 | 起点未落在真实环路上 | 移动起终点到环路，或改成单程 |
| 上下两个大环由窄段拼接 | 只满足首尾闭合，路线形成双环或哑铃形 | 保留一个真实环，或沿全区外围重画单一大环 |
| 长线密集绕小街区 | 用景点堆叠或目标里程驱动节点 | 先锁定连续主廊道，再调整真实目标里程 |
| 跑步、骑行缺少方向 | 前端只对部分形态启用箭头 | 为所有运动类型和两种形态绘制方向 |
| 标记落在线外 | 使用平均折线位置或错误字段 | 使用真实节点坐标或轨迹最近点 |

## 5. 运动类型规则

### 步行

- 优先公共人行道、公园正式园路、滨水步道和开放街区。
- 园区闭环使用真实环路节点，避开植物展区和建筑尽端。
- 根据开放时间记录公园门区限制。

### 跑步

- 优先连续跑道、绿道、滨水步道和低冲突人行空间。
- 长距离线路先确定连续跑步母线，再选择补水与厕所。
- 避免大量信号灯、小街区折角和为凑里程形成的往返。
- 前端显示全程方向箭头。

### 骑行

- 优先非机动车道、公共道路和已核实可骑行绿道。
- 避开园内纯步行空间、禁骑道路、抬车通道和不明门禁。
- 20 公里以上线路优先使用徐汇滨江、龙腾大道、植物园外围、华泾和已核实连接道路。
- 地铁站只承担起终点或接驳语义，偏离骑行主路时不进入导航骨架。

## 6. 区域覆盖

组合路线覆盖徐汇滨江与西岸、龙华、徐家汇、衡复风貌区、上海植物园、康健园、漕河泾和华泾。组合门禁通过 `popular_area_ids` 或名称与区域标签统计覆盖，视觉验收再确认轨迹实际经过相应公共空间。

同一区域内保留多种运动与多个里程档时，各路线采用不同入口、方向、道路骨架或主题，降低大量同质路线。长距离骑行承担跨区域连接，短距离路线保持单一区域内清晰、连续和易识别。

## 7. 网页目录与状态

- `route_catalog.json` 与路线 GeoJSON 始终导出 90 条路线。
- `accepted` 与 `needs_review` 均在地图和路线目录中可查看。
- 推荐结果与正式导航选择仅使用 `validation_status == accepted` 的路线。
- 页面显示运动类型、里程档和 `strict_loop` / `one_way` 形态。
- 待考证路线清晰显示状态，退出自动推荐与正式导航入口。
- 最终发布前检查展示 90 条、三种运动各 30 条、环线与单程统计以及推荐和导航过滤。
- 过程门禁允许 `needs_review` 留在可查看目录；最终门禁使用 `--require-all-accepted`，验收状态达到 90 条 `accepted`、0 条 `needs_review`。

## 8. 视觉验收清单

在路线全景和问题区域街区级缩放下分别检查：

1. 目视只存在一条清晰主线或一个清晰主环。
2. 无矩形回环、局部折返、支叉、断头和重复走廊。
3. 无双环、哑铃形、葫芦形、长柄环和多叶形态。
4. 起终点和途经点与轨迹吻合。
5. 箭头方向与节点顺序一致。
6. POI 标记不改变主线。
7. 路线名称与实际覆盖区域和距离一致。

任何一项失败时保持 `needs_review`，回到骨架设计阶段。
